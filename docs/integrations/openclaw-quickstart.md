# OpenClaw quickstart

The end-user OpenClaw guide lives in [`examples/openclaw/`](../../examples/openclaw/).

Use that guide if you want to quickly point an existing OpenClaw setup at
TokSuan, get a saved-money receipt, and set a budget.

Use [`openclaw.md`](openclaw.md) if you are integrating OpenClaw at the code
level and need the full agent/session header contract.
