# Hermes-Agent quickstart

The end-user Hermes-Agent guide lives in
[`examples/hermes-agent/`](../../examples/hermes-agent/).

Use that guide if you want to quickly point an existing Hermes setup at
TokSuan, get a saved-money receipt, and set a budget.

Use [`hermes.md`](hermes.md) if you are integrating Hermes at the code
level and need the full agent/session header contract — including the
`pre_llm_call` plugin hook, fallback_model wiring, and the per-session
rollup view.
